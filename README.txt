STORM GAMING WEBSITE

Sådan bruger du websitet:
1. Pak ZIP-filen ud.
2. Åbn index.html i Chrome, Edge eller en anden browser.
3. Klik på "Spil" og prøv spillene.

Filer:
- index.html = selve hjemmesiden
- style.css = designet
- script.js = funktionerne

Websitet virker direkte i browseren og kræver ikke Python eller pygame.

Gør websitet offentligt med GitHub Pages:
1. Opret et nyt repository på github.com, og vælg Public.
2. Upload alle filer fra denne mappe til repositoryets main-branch.
3. Gå til Settings > Pages, vælg GitHub Actions som source.
4. Vent på workflowet "Deploy website to GitHub Pages" under Actions.
5. GitHub viser derefter den offentlige URL under Settings > Pages.
